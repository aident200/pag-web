1. Objetivo

El objetivo de nuestra empresa es ofrecer un dispositivo IoT para el hogar que permita controlar diferentes elementos de la casa de forma sencilla desde el móvil. Buscamos combinar tecnología, comodidad y seguridad para que los usuarios puedan automatizar tareas y controlar su hogar desde cualquier lugar.

2. A quién va dirigido

Nuestro producto está dirigido principalmente a jóvenes y adultos que quieran convertir su casa en un hogar inteligente. También está pensado para personas que buscan ahorrar energía, mejorar la seguridad y controlar sus dispositivos de forma cómoda desde el móvil.

3. Análisis funcional

El dispositivo IoT Nidoo Hub permite controlar diferentes dispositivos inteligentes del hogar mediante una aplicación móvil. Se conecta a Internet mediante Wi-Fi y puede comunicarse con otros dispositivos. El usuario puede encender y apagar luces, controlar enchufes, consultar sensores de temperatura y recibir avisos en el móvil. También permite crear automatizaciones para que algunas acciones se realicen de forma automática.
